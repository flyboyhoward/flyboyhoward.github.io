# Wenhao Wang — Academic Homepage

A responsive, static academic homepage for GitHub Pages. No installation, JavaScript, or build step is required.

## Preview and edit

Open `index.html` in a browser to preview. Edit the biography, publications, and education directly in `index.html`. Visual styles are in `assets/style.css`.

To add a portrait, put your image in `assets/` and replace the `.portrait` monogram in `index.html` with an image using the same class and descriptive alt text. No email address or CV is included because these were not supplied.

## GitHub Pages

Commit and push these files to `flyboyhoward/flyboyhoward.github.io`. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select the branch containing these files, and select **/ (root)**. The intended address is https://flyboyhoward.github.io/ once GitHub Pages deploys successfully.
